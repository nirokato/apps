        How it works
        
      
        Mirage is a small vision model from Cactus Compute. One pass over an image returns a scene summary, named objects with boxes and outlines, the text it can read, and how the objects relate. Scores run from 0 to 1.
        
      
        The engine is Cactus's WebAssembly runtime (1.3 MB, served from this site). The weights (21.6 MB) come from Hugging Face on the first run, are checked against a known SHA-256, and are then kept in this browser. Your image is decoded, scaled to 1024 px on its long edge and handed to the model in a background worker; no part of it is sent anywhere.
